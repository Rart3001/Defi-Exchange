## 2024-05-24 - Dynamic ARIA Labels in State-driven Inputs
**Learning:** Found a pattern where input fields (like the "Swap Amount" field) change their functional purpose based on another component's state (e.g., a dropdown selecting "Ether" vs "Crypto Dev Tokens"). This caused a mismatch for screen readers, as the input had a generic generic placeholder ("Amount") and no explicit label.
**Action:** When a form field's meaning changes based on external state, use React state (`ethSelected`) to dynamically render specific `aria-label` and `placeholder` text (e.g., `aria-label={ethSelected ? "Amount of Ether to swap" : "Amount of Crypto Dev Tokens to swap"}`). Also implemented the `role="tab"` and `role="tablist"` alongside `aria-selected` to make React state-driven custom tabs accessible to keyboard and screen reader users.
